Open dashboard.html in a browser. To see the original portal entrance, open index.html and select Explore Command Center Preview.

TO INSTALL ON GITHUB PAGES
Upload the six files to the root of your Blackcell-Corporate-Portal repository. Do not upload them to your NEXUS or Gunner Collection Portal repositories. Confirm any existing customizations before replacing files. Github Pages serves index.html at the repo root; use /dashboard.html to open the admin preview.

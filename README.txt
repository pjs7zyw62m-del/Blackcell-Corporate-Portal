TEST
  Extract all files together into one folder. Open index.html.
  Click Explore Command Center. View NEXUS/GUNNER cards.
  The NEXUS card will request a separate NEXUS address; no address is hardcoded.
  Both navigation links use the same browser tab. Use browser Back to return.

SECURITY LIMITS
  This is NOT an authenticated site. The Secure Sign In button is disabled.
  Region/server selection is only UI and does not supply a real security factor.
  Account menu options are demonstrations, not real account operations.
  Do NOT publish as a secure private portal or replace blackcellcorp.com until
  server-verified email/password, access-code and region/server checks, and
  an independent NEXUS destination, have been implemented and tested.

DO NOT replace NEXUS or Gunner's existing working websites with this preview.
